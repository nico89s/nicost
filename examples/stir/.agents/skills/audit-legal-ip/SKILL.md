# Legal & IP Audit Skill — License Compliance & Provenance Triage

## Objective
Identify open-source license obligations, verify media asset commercial rights, and triage AI-generated code provenance. Never provide definitive legal conclusions; frame all outputs as compliance observations.

---

## 1. 4-State Provenance Classification Model

- `VERIFIED`: Known permissive license (MIT, Apache 2.0, BSD) or explicitly licensed proprietary asset.
- `REVIEW`: Dual-licensed packages, missing license declarations, or ambiguous terms.
- `UNKNOWN`: Unattributed AI-generated logic, undocumented external assets, or unverified snippets.
- `POTENTIAL_CONFLICT`: Strong copyleft (GPL v2/v3, AGPL, SSPL) mixed into proprietary distribution.

---

## 2. Audit Checkpoints

1. **Open-Source License Scanning**:
   - Check all direct and transitive dependencies for viral copyleft licenses incompatible with closed-source commercial distribution.
2. **Asset Origin & Commercial Rights**:
   - Verify licenses for embedded fonts (SIL Open Font License vs restricted commercial), icons, illustrations, and audio.
3. **AI Code Provenance Triage**:
   - Triage complex algorithmic sections generated by AI models; flag snippets of unknown provenance for human review.
4. **Legal Disclaimer Constraint**:
   - Present observations objectively. Never conclude "legally compliant" or "indemnified".

---

## 3. CLI Inspection Recipes

```bash
# Detect copyleft licenses in package manifests
grep -rnEI '"license":' package.json node_modules/*/package.json 2>/dev/null | grep -iE '(GPL|AGPL|SSPL)'

# Inventory font assets
find assets/ public/ -iname "*.ttf" -o -iname "*.otf" -o -iname "*.woff*" 2>/dev/null

# Inspect recent commit authorship and AI commit messages
git log --pretty=format:"%h - %an: %s" -n 20
```

---

## 4. Output & Classification

Record findings in `docs/audit/findings/` using status `BLOCK`, `WARN`, `REVIEW`, or `PASS`.
