# Frontend Skill — UI Standards & Component Mechanics

## Objective
Ensure all user interfaces, screens, modals, and interaction states strictly conform to [`docs/DESIGN_GUIDELINES.md`](../../../docs/DESIGN_GUIDELINES.md).

---

## 1. Principles

1. **Inspect Before Coding**:
   - Inspect [`docs/DESIGN_GUIDELINES.md`](../../../docs/DESIGN_GUIDELINES.md) and existing shared components.
2. **Reuse Existing Primitives**:
   - Never write raw, unstyled buttons or one-off containers. Reuse project UI primitives.
3. **Responsive & Mobile-First**:
   - Ensure layouts scale smoothly between mobile screen widths and desktop viewports.
4. **Interactive States**:
   - Every input and action component must account for: default, hover/active, focus, disabled, loading, and error states.
